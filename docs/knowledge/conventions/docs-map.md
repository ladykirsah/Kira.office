# Map of docs/ with staleness verdicts

The repo's `docs/` folder mixes as-built references, module specs, design specs, runbooks, and planning-era documents. **Repo docs in this project have lied before** — this map records, per file, what it is and what specifically drifted. Verdicts: **CURRENT** (trust it), **PARTLY STALE** (trust the framing, verify the details named), **HISTORICAL** (background only).

Common drift causes to keep in mind while reading anything dated before these events:

- **Jul 21 2026**: all hosts consolidated onto `airplusauto.com` — any doc naming `admin.homeseeker.me` / `api.homeseeker.me` is pre-move ([platform](../platform/index.md)).
- **Jul 30 2026**: financial two-book rework merged (migrations through 0073), then defect claims (0077–0079), credit rebuild (#99), staff logins (#129) — docs frozen Jul 26 don't know these ([commerce](../commerce/index.md), [auth](../auth/index.md)).
- Repo migration head is **0087** (applied to prod before the Insight merge — verify with `wrangler d1 migrations list kira-office --remote`); several docs stop at 0047. See [state/current.md](../state/current.md).

## Source-of-truth chain

`AGENTS.md` (repo root — project rules, TDD requirement, stack) says: read `docs/DECISIONS.md` first, then `docs/STATE_OF_THE_BUILD.md`. STATE_OF_THE_BUILD declares the chain **DECISIONS.md → STATE_OF_THE_BUILD.md → reference docs**, with this file and code winning over older planning docs. For schema, the SQL migration files in `packages/db/migrations/` are the ONLY source of truth.
